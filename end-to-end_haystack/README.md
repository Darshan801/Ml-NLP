# Haystack RAG Q&A System

A Retrieval-Augmented Generation (RAG) system built with Haystack, Pinecone vector database, and Hugging Face models for question-answering over PDF documents.

## Features

- **PDF Ingestion**: Convert PDFs to text, chunk them, and store in vector database
- **Vector Search**: Semantic search using Pinecone vector database
- **RAG Pipeline**: Retrieve relevant documents and generate answers using LLMs
- **Multiple LLM Options**: Support for both local and API-based models
