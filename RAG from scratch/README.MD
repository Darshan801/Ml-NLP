# Mini NLP → RAG → LLM Project

This repository contains a complete end-to-end learning project that starts from **basic NLP concepts** and gradually builds up to a **Retrieval-Augmented Generation (RAG) system using an LLM**.

It is ideal for:
- NLP & ML beginners  
- Understanding how RAG works internally  
- Interview preparation  
- GitHub portfolio projects  

---

## What This Project Does

✔ Cleans and preprocesses text  
✔ Builds a vocabulary and Bag-of-Words vectors  
✔ Encodes labels for ML  
✔ Creates text embeddings  
✔ Stores embeddings in a vector database  
✔ Retrieves relevant documents for a query  
✔ Uses an LLM to generate a **human-readable answer**  

---

## Concepts Covered

- NLP preprocessing
- Bag of Words (BoW)
- Vocabulary creation
- Label encoding
- Vector similarity search
- Embeddings
- FAISS vector index
- Retrieval-Augmented Generation (RAG)
- Prompt engineering
- LLM answer generation
