# Student-score-prediction

## Project Overview
This project focuses on predicting student exam_scores based on their hours_studied

## Structure
- `src/` – student-score-prediction notebook
- `data/` – dataset files
- `venv/` – virtual environment (ignored)

## Technologies
- Python
- Pandas, Matplotlib
- Linear Regression , mean_absolute_error , mean_squared_error ,r2_score
- Git & GitHub

## Results
- predict student exam_scores based on hours_studied
- predict student exam_scores based on previous_scores
- predict student future_exam_scores from their previous_score and current_exam_score based on hours_studied

python -m venv venv
