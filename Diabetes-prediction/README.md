# Diabetes prediction

## Project Overview
This project focuses on predicting Diabetes based on their [BMI , AGE]

## Structure
- `src/`  - Diabetes-prediction notebook
- `data/` – dataset files
- `venv/` – virtual environment (ignored)

## Technologies
- Python
- Pandas, Matplotlib
- sklearn ( KNeighborsClassifier , StandardScaler ,train_test_split,accuracy_score )
- Git & GitHub

## Results
- predict Diabetes based on BMI and Age

```bash
python -m venv venv
