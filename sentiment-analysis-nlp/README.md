#sentiment analysis using NLP

## overview
This project implements a sentiment analysis system that classifes text as positive  or negative using machine learing and NLP techniques

## technologies 
-python
-pandas
-Scikit-learn
-TF-IDF Vectorization
-Logistic Regression
- Naive Bayes
-Git and GitHub

## project structure
- `data/` - dataset files
- `src/` - source code
- `venv/` - virtual environment (ignored)

## how to run 

```bash
python -m venv ./venv
./venv/Scripts/activate

pip install -r requirement.text
